{{ template "button" (dict "label" "Open publisher simulator →") }} {{ template "card-end" . }} {{ template "card-start" (dict "title" "Continuous traffic") }}

Keep a steady stream of realistic attributed traffic flowing so dashboards, spend, fill and earnings stay live. This runs as a background job (no server button — it's a long-running process), started from the CLI or Tilt:

  • make traffic — continuous sim at a set speed (DEMO_RPS, default 5). Ctrl-C to stop.
  • Tilt sim-continuous resource — same thing, start/stop from the Tilt UI.
  • make demo — one-off baseline burst + rollups (runs automatically on tilt up).
  • make reset — wipe all data (Postgres+ClickHouse+Redis) then re-populate for a fresh run.
