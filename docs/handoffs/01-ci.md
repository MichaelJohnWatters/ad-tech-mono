# Session: CI pipeline (GitHub Actions)

## Why now
2026-08-06: a chart committed without `helm lint` (YAML comment inside a {}
flow mapping) broke the next `helm upgrade` — with the stack already torn
down. Same day, `go test | tail` in &&-chains masked failing tests into
deploys THREE times. All preventable by CI. We commit straight to main.

## Goal
A GitHub Actions workflow on every push to main:
1. `go build ./...` + `go vet ./...`
2. `go test ./...` (units only — NO integration tag; they need the stack)
3. `helm lint k8s/helm/adtech` + `helm template ... | kubectl apply
   --dry-run=client -f -` (kubectl in CI: use a dry-run-capable validator
   like kubeconform if kubectl-vs-cluster is awkward)
4. `gofmt -l` check
Fast (<5min), no cluster needed, badge in README optional.
